# Project creation and setup
- firsly i created this directory 
- next i created a virtual environment using the command "uv venv" then i later on activated the virtual environment using the command ".venv\Scripts\activate" 
- Next i installed Django in the venv using the command "uv pip install Django" then created the Django project using "django-admin startproject config ."( the . at the end indicates that the project should be created in this folder)

# Now Assignment
1. we had to create a new app bibliotheque
python manage.py startapp bibliotheque
2. created the different models for the library and author in the models.py of that app
3. registered the app bc without registering we cannot migrate(added the app in the settings.py of the config app
4. migrated the two models using python manage.py makemigrations then python manage.py migrate
5.register both models in the admin.py using for example "admin.site.register(Auteur)" so that we can access the admin dashboard
6. created an admin superadmin using "python manage.py createsuperuser" then running the django app using python manage.py runserver
